# INF204 - Prática Laboratorial 04

Aplicativo desenvolvido com React Native e Expo para a Prática Laboratorial 04.

## Integrantes

- Lucas Oliveira Paiva - Matrícula: 27940
- Gabryel Messias Oliveira de Assis - Matrícula: 27316

## Funcionalidades

- Votação independente para três candidatos.
- Atualização segura de estado com callbacks do `useState`.
- Total de votos calculado como dado derivado.
- Porcentagem de votos por candidato, incluindo tratamento do estado sem votos.
- Identificação do mesário por meio de um `TextInput` controlado.
- Reinicialização simultânea de todos os votos.

## Como executar

```bash
npm install
npx expo start
```

No terminal do Expo, use o QR Code para abrir no Expo Go ou pressione `w` para executar no navegador.

## Testes

npm test
