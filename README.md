# INF204 - Prática Laboratorial 06

Aplicativo desenvolvido com React Native e Expo para a Prática Laboratorial 06.

## Funcionalidades

- Navegação principal em pilha com Native Stack.
- Navegação inferior com abas para Início e Ajustes.
- Aninhamento das abas dentro da Stack principal.
- Passagem do parâmetro `nomeUsuario` para a tela de detalhes.
- Retorno programático com `navigation.goBack()`.
- Cores de abas ativas e inativas e ícones do Expo.
- Organização do projeto em `src/screens`, `src/routes` e `src/utils`.

## Como executar

```bash
npm install
npx expo start
```

No terminal do Expo, use o QR Code para abrir no Expo Go ou pressione `w` para executar no navegador.

## Testes

```bash
npm test
```
